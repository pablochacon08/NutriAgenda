# Especificación de requerimientos (SRS)

El documento de especificación de requerimientos de software, versión 1.0, se entrega en Aula Virtual en formato PDF. Contiene 71 requerimientos funcionales, 28 requerimientos no funcionales clasificados según Sommerville, las reglas del negocio, los riesgos, los asuntos pendientes de confirmar con la cliente y, como apéndices, el acta de conformidad firmada y las capturas del prototipo.

No se publica aquí porque su apéndice A incluye datos personales de la cliente.
